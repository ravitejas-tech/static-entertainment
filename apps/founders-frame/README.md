# Founders Frame

The Founders Frame website: a curated networking and events community for Pune's founders, investors and business leaders. It is a static React Router SPA (`ssr: false`, public pages prerendered) on the same Supabase backend and admin panel as Echoverse.

```bash
yarn dev:founders-frame                     # from the repo root → http://localhost:7302
yarn workspace founders-frame build         # static build in apps/founders-frame/build/client
```

The design and pages are still to come. Rules: `docs/rulebooks/frontend.md`.
